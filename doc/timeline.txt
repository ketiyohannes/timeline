*timeline.txt*                  Chronological Codex changes for Neovim

==============================================================================
INTRODUCTION                                                    *timeline*

Timeline records the repository after each observed Codex tool call in an
isolated Git ref, then presents those changes chronologically in Neovim. It
imports existing Git history and never checks out a snapshot or uses the
repository's normal index.

==============================================================================
COMMANDS                                                  *timeline-commands*

:Timeline
    Open the three-pane snapshot browser. Changes shows ordered messages,
    Codebase shows every file at the event, and Code shows the complete file
    with bold + and - highlights.

    Press <CR> to move right, 1/2/3 to focus a pane, [c and ]c to traverse
    events, r to refresh, and q or <Esc> to close. Press / from any pane to
    search commit messages or change numbers, then n or N to move through
    matching commits. See |timeline-search|. Press F to search paths in the
    selected commit and [f or ]f to move through file matches. See
    |timeline-file-search|. The panes resize with the editor. Selecting a
    changed file scrolls its complete source snapshot so its first highlighted
    line is at the top of the Code pane.

:TimelineSync
    Import the current HEAD's reachable commit history, then capture modified
    and untracked state. This also happens automatically on first file open.

:TimelineAnnotate
    Add signs to current lines. "01" means event 1 introduced the line.

:TimelineClear
    Remove signs from the current buffer.

:TimelineSession
    Choose among the continuous project, demo, and legacy timelines.

:TimelineEnable / :TimelineDisable
    Resume or explicitly disable automatic recording for this repository.

:TimelineInstallHooks / :TimelineUninstallHooks
    Safely add or remove Timeline's Codex lifecycle handlers. Unrelated hooks
    are preserved and hooks.json is backed up before each change. Restart
    Codex after installing hooks.

]t / [t
    Jump to the next or previous annotated line.

==============================================================================
COMMIT SEARCH                                             *timeline-search*

Press / from any Timeline pane to open the "Search commits:" prompt. The query
is case-insensitive and matched literally against the visible change number and
commit message. For example:
>
    auth
    #012
    base
<
The first match at or after the current event opens immediately. All matches
are highlighted in Changes, whose title displays the result count. Press n for
the next match or N for the previous match from any pane. Navigation wraps at
the beginning and end of the results.

Opening a result reconstructs the complete codebase at that event. Codebase
contains every file that existed then, and Code displays the selected full file
with the event-local additions and removals highlighted.

Submit an empty query to clear the search and highlights. When no commit
matches, the current event remains selected and the Changes title displays
"no matches". Commit search does not inspect file contents, paths, timestamps,
or commit hashes. Use |timeline-file-search| to search snapshot paths.

==============================================================================
FILE SEARCH                                          *timeline-file-search*

Press F from any Timeline pane to search the complete file tree at the selected
commit. The prompt includes the active change number, for example:
>
    Search files in #012: src/api
<
Queries are case-insensitive literal matches against complete
repository-relative paths. The first result at or after the currently selected
file opens immediately. All results are highlighted in Codebase, whose title
displays the count. Press ]f for the next match or [f for the previous match
from any pane. Navigation wraps at the beginning and end.

Search uses the historical snapshot, not the current working directory. It
includes unchanged files, plus a deleted file at its deletion event. Opening a
result displays the complete historical file in Code with event-local changes
highlighted.

Submit an empty query to clear file search. Changing commits also clears it so
paths from one filesystem snapshot never leak into another. File search matches
paths only; it does not inspect file contents.

==============================================================================
SETUP                                                        *timeline-setup*

>lua
    require("timeline").setup({
      annotate_on_buf_enter = true,
      auto_sync = true,
      virtual_text = false,
      session = nil,
      colors = {},
    })
<

With lazy.nvim:
>lua
    {
      "ketiyohannes/timeline",
      lazy = false,
      config = function()
        require("timeline").setup()
      end,
    }
<

After :Lazy sync, run |:TimelineInstallHooks| and restart Codex. Verify with:
>
    :checkhealth timeline
<

The palette adapts to dark and light backgrounds. Pass add_bg, add_fg,
delete_bg, delete_fg, change_bg, change_fg, accent_bg, or accent_fg in
`colors` to customize it.

==============================================================================
STORAGE                                                     *timeline-storage*

The continuous project history lives at
refs/codex-timeline/session-project. This internal namespace is retained for
compatibility with releases published under the old Codex Timeline name.
Pending state and locks live below .git/codex-timeline/.

Existing Git history has commit-level ordering. Future Codex changes have
completed-tool-call ordering. Snapshots include non-ignored tracked,
untracked, renamed, and deleted files without modifying HEAD or the index.

The deprecated |:CodexTimeline| commands and require("codex_timeline") remain
available for existing configurations.
